# 生成、推理入口和实验代码

> 整理日期：2026-10-03。行号对应本次整理的源码；之后编辑源码可能移动行号。数字示例会注明是手算还是实际运行。


训练后的模型会给下一 token 打分，但不会自动把一整篇故事一次输出。生成循环每次选择一个 ID，追加到已有输入，再预测下一个；分词器最后把 ID 还原成文字。

像接龙：开头由你提供，每次接出的内容又变成下一轮的提示。temperature 和 Top-P 决定候选概率怎样调整，抽样决定本轮接哪一个。

| 模块 | 输入 → 输出 |
|---|---|
| inference.main | 文件路径和生成参数 → 已加载模型、交互循环 |
| tokenizer.encode | prompt 字符串 → ID 列表 |
| generate | `[B,S]` prompt → prompt 加新增 ID |
| _top_p_filter | 候选分数 → 部分候选分数为 -inf |
| tokenizer.decode | 完整 ID → 续写文字 |

| 565 | 原 ID 掩码为 True 的分数设为 -inf；masked_fill 返回新结果，不原地修改调用方原 logits。 |
| 567 | 返回过滤后的 logits。 |

实际运行的四候选例子：原 ID 概率 `[0.10,0.50,0.25,0.15]`，p=0.7。

| 步骤 | 结果 |
|---|---|
| 降序后的 ID | `[1,2,3,0]` |
| 概率 | `[0.50,0.25,0.15,0.10]` |
| 累计 | `[0.50,0.75,0.90,1.00]` |
| 初始移除掩码 | `[False,True,True,True]` |
| 右移后 | `[False,False,True,True]` |
| 原 ID 顺序掩码 | `[True,False,False,True]` |
| 再 softmax | `[0,0.6667,0.3333,0]` |

负无穷的指数为零，过滤候选不会被抽到。不能填 0，因为 `exp(0)=1`。p=0.2 时最高概率项仍保留。

边界核对：本例 p=0.75 时，前两项累计恰好是阈值，但代码使用 `>` 再右移，所以实际保留前三项。源码注释的“达到阈值的最小集合”在这个边界并不严格成立，更准确是保留到首次严格越过阈值的项。浮点误差也会影响相等边界。本次只记录现有行为，没有修改生成算法。

## 7. 实验脚本、notebook 和测试怎样看

`run_scripts/*.sh` 是 Bash 入口：`set -euo pipefail` 开启严格错误处理；`cd` 按脚本位置回到仓库根；反斜杠把一条训练命令分成多行。它们运行的仍是 main_train。

| 文件 | 改变的内容 | 阅读注意 |
|---|---|---|
| baseline.sh | 固定模型/训练配置 | 比 run1 大，不是已验证的最低配置 |
| no_rms_norm.sh | 去掉归一化 | 其他条件也需对齐再比较 |

当前 sweep 脚本有 `set -e`，训练命令失败时可能在后面的 `$?` 分支之前就退出；“失败继续下一组”的注释不保证实际生效。脚本只传 wandb_project 不会启用 WandB，必须额外加 --wandb。Linux/Git Bash/WSL 能运行这些 .sh，PowerShell 使用手册中的原生命令。

`vlogs/*.ipynb` 与 `learn.ipynb` 是上游实验笔记，有机器路径和历史输出；两份上游 notebook 本来为空文件。它们不属于主训练依赖，也没有在本次重新执行。`test.py` 是字节练习草稿，不是训练入口；真正验证在 tests。

测试中的 adapters 把课程测试接口连接到你的函数；fixtures 是小型测试语料与参考权重；_snapshots 保存参考数值。不要为了让测试通过而改写快照。pytest 与 unittest 的命令见 [操作手册](../autodl-guide.md)。

## 常见坑与速查

- `nn.py:513` 返回可以超过上下文长度，但模型本轮只看最后的窗口。
- `nn.py:530` 使用随机抽样，相同 prompt 不保证相同输出。
- `nn.py:536` batch>1 时没有逐条完成状态，不能当作完整的批量生成管理。
- `nn.py:554/559` 恰好等于 Top-P 阈值时可能多保留一个候选。
- `inference.py:90/135` CLI 显式尺寸会覆盖配置，不匹配存档会加载失败。
- `inference.py:100` tokenizer 与训练词表必须一致，否则相同 ID 会对应错误文本。
- `inference.py:149–175` 没有自动聊天历史，输出还包含 prompt。

| 概念 | 一句话 | 代码位置 |
|---|---|---|
| 自回归 | 追加新 token，再预测下一项 | `nn.py:510–533` |
| 温度 | 调整概率集中程度 | `nn.py:522` |
| Top-P | 按累计概率过滤候选 | `nn.py:543` |
| 配置恢复 | 用训练尺寸搭同样模型 | `inference.py:84–119` |
| 解码 | ID 查 bytes，再拼成文字 | `tokenizer.py:133` |
| 实验入口 | 同一训练函数的不同设置 | `run_scripts/` |
