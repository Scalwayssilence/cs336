# 模型：从 token ID 到词表分数

> 整理日期：2026-10-03。行号对应本次整理的源码；之后编辑源码可能移动行号。数字示例会注明是手算还是实际运行。


你先有一串 ID，例如 `[12,35,8]`。模型要为每个位置预测下一个 ID；整数本身没有可直接用于预测的词义，所以先查 Embedding 得到可学习向量，再通过注意力和 FFN 加工。

像几个人讨论一句话：Attention 让位置之间交换信息，FFN 对各自的信息加工。残差连接把加工结果加回已有表示，最后 LM Head 给全部候选打分。

```text
ID [8,256] → Embedding [8,256,256]
 → 4个Block → Final RMSNorm → LM Head [8,256,10000]
```

本章覆盖 `nn.py` 的模型部分；生成方法见 [推理章节](05-inference-experiments.md)。

## 3. RMSNorm：控制每个 token 的特征尺度

源码：[nn.py L66–L100](../../assignment1-basics/cs336_basics/nn.py#L66)。

公式是 `x / sqrt(mean(x²)+eps) × g`，不减均值；每个 token 单独计算分母，g 是所有位置共享的可学习缩放。

源码：[nn.py L136–L202](../../assignment1-basics/cs336_basics/nn.py#L136)。

每对相邻特征 `(a,b)` 按当前位置的角度旋转。不同维度对频率不同；旋转保持长度和形状。固定内容时，Q/K 点积中的位置因素取决于相对位置。

|---|---|

## 常见坑与速查

- `nn.py:47` 的参数按 `[out,in]` 存储，数学公式若写行向量，需要对应权重转置。
- `nn.py:93` 只沿最后一维归一化；跨 batch 求均值会改变算法。
- `nn.py:199/200` 使用相邻偶奇维配对；位置必须落在缓存内，每头维度须为偶数。
- `nn.py:255` 不能把整行都屏蔽，否则 softmax 可能得到 NaN。
- `nn.py:400/401` 的第二次残差使用第一次更新后的 x，不能拿最初 x 替代。
- `nn.py:393/410` 对未知 FFN 会报错，但非法 norm_mode 直接调用 Block 时会静默直通；训练 CLI 的 choices 能拦住它。

| 概念 | 一句话 | 代码位置 |
|---|---|---|
| Linear / Embedding | 投影特征 / 按 ID 查向量 | `nn.py:25/53` |
| RMSNorm | 逐 token 控制最后一维尺度 | `nn.py:72` |
| SwiGLU | 两分支相乘，再回到 D | `nn.py:118` |
| RoPE | 旋转 Q/K 的特征对 | `nn.py:147` |
